# InternSpark Internship Project

A full-stack JavaScript internship project covering REST APIs, React SPAs, JWT authentication, and Docker deployment.

## 📋 Project Overview

| Task | Description | Tech Stack | Folder |
|------|-------------|------------|--------|
| **Task 1** | RESTful API with CRUD operations | Node.js, Express, MongoDB | [`Task-1-REST-API`](./Task-1-REST-API) |
| **Task 2** | React SPA consuming REST API | React, React Router, Axios | [`Task-2-React-SPA`](./Task-2-React-SPA) |
| **Task 3** | Authentication & Protected Routes | JWT, bcrypt, React Context | [`Task-3-Auth-JWT`](./Task-3-Auth-JWT) |

## 🛠 Tech Stack

- **Backend:** Node.js, Express.js, MongoDB, Mongoose
- **Frontend:** React.js (Vite), React Router, Axios
- **Authentication:** JWT, bcryptjs
- **Tools:** Postman, Git, VS Code

## 📚 Tasks Breakdown

### Task 1 — RESTful API
- CRUD endpoints (`GET`, `POST`, `PUT`, `DELETE`)
- Mongoose schemas with validation
- Error handling & logging
- **Port:** 5001

### Task 2 — React SPA
- Fetch API consumption
- Loading & error states
- React Router navigation
- Custom professional UI
- **Port:** 5173

### Task 3 — Authentication & Protected Routes
- User signup/login with bcrypt-hashed passwords
- JWT token issuance & verification
- Protected API endpoints
- Protected client routes
- **Backend Port:** 5003 | **Frontend Port:** 5174
